# Labubu Locator

**Labubu Locator** — a playful and interactive web app to explore, track, and enjoy Labubu collectibles.  
Live site: https://labubulocator.me/

## 🎉 Overview
Labubu Locator is a fun tool for collectors and fans of the Labubu universe. Whether you're browsing figures, tracking your finds, or just exploring, the app provides a smooth and responsive experience.

## 🚀 Features
- Easy navigation with a clean, friendly UI  
- Search & filter through collectible items  
- Visual browsing of Labubu characters and sets  
- Fully responsive on all devices  
- Fast and lightweight  

## 🛠️ Tech Stack
(Adjust as needed)
- Frontend: React / Next.js  
- Styling: Tailwind CSS  
- Deployment: Vercel / Netlify / GitHub Pages  

## 📦 Local Development
Clone the project:
git clone https://github.com/your-username/labubu-locator.git  
cd labubu-locator

Install dependencies:
npm install

Run dev server:
npm run dev

Build for production:
npm run build

## 🧩 Configuration
If environment variables are required:
cp .env.example .env  
Then update the `.env` file with necessary keys.
